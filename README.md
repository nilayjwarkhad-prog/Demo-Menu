# The Royal Plate — Digital Menu

An authentic, modern digital dining experience and interactive restaurant menu.

## ✨ Features

- **Categorized Menu**: Starters, Soups, Main Course, Rice & Breads, Desserts, and Beverages.
- **Dietary Filters**: Veg & Non-Veg filtering.
- **Instant Search**: Quickly search dishes by name.
- **Interactive Ordering**: Live cart, item quantities, and order summary drawer.
- **Responsive Design**: Mobile-first, elegant royal gold-and-dark aesthetic.

## 🚀 Getting Started

Open `index.html` directly in any modern browser, or host it with GitHub Pages / Vercel / Netlify.
